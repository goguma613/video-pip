# 🎬 고화질 영상 PIP (Picture-in-Picture)

영상을 **원본 화질 그대로** 항상 위에 뜨는 작은 창으로 빼내, 다른 작업을 하면서 보게 해 주는 유저스크립트입니다.
**Document Picture-in-Picture** 기술로 사이트가 재생 중인 원본 영상을 통째로 옮기기 때문에 화질 손실이 없고(4K 포함), 그 위에 꼭 필요한 컨트롤만 얹었습니다.
(Tampermonkey · Violentmonkey 등 유저스크립트 매니저에서 동작)

## ✨ 기능

- **원본 화질 그대로** — 다운스케일·재인코딩 없이, 사이트가 재생 중인 영상 그대로
- **한 번에** — 영상에 마우스를 올리면 나오는 ⧉ 버튼, 또는 `Alt+P`
- **필요한 컨트롤만** — 재생/일시정지 · 시크바 · ±10초 · 볼륨 · 배속 · 닫기 (마우스를 올리면 나타나고, 가만히 두면 사라짐)
- **화질 표시 · 바로 바꾸기** — 지금 실제로 재생 중인 해상도(`1080p`, `4K` 등)를 보여 주고, 유튜브에선 그 표시를 누르면 바로 화질을 고를 수 있음. **최고 화질 · 항상**을 고르면 영상마다 최고 화질로 맞춤
- **깔끔한 복귀** — 창을 닫으면 영상이 원래 자리로, 재생 상태 그대로. 사이트 레이아웃도 그대로
- **창 크기 기억** — 마지막 크기로 열고, 영상 비율에 맞춤(세로 영상·쇼츠는 세로 창)
- **탭 전환 자동 PIP** (선택) — 다른 탭으로 가면 PIP 창이 자동으로 열림 (Chrome 134+)
- **어느 사이트든** — 유튜브는 물론 영상이 있는 대부분의 사이트. 사이트별로 끌 수도 있음
- **사이트를 방해하지 않음** — 페이지에 떠 있는 패널이 없고, 사이트 단축키(유튜브 `k`, `f` 등)도 그대로

## 🚀 설치 방법 (3단계)

> Chrome · Edge · Whale(네이버) 모두 같은 방식입니다.

### 1단계 — 유저스크립트 매니저 설치
- **추천 → [Tampermonkey](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo)**
- 대안 → [Violentmonkey](https://chromewebstore.google.com/detail/violentmonkey/jinjaccalgkegednnccohejagnlnfdag)

### 2단계 — ⚠️ 사용자 스크립트 허용 켜기 (꼭 필요!)
최신 크롬/웨일(Manifest V3)에서는 이걸 켜지 않으면 스크립트가 **실행되지 않습니다.** 아래 둘 중 **하나만** 하면 됩니다.

- **방법 A — 최신 크롬/엣지(138+)**: Tampermonkey 아이콘 **우클릭 → "확장 프로그램 관리"** → **"사용자 스크립트 허용(Allow user scripts)"** 토글 **켜기**
- **방법 B — 웨일/구버전 크롬**: 주소창에 `chrome://extensions`(웨일은 `whale://extensions`) → **"개발자 모드"** 토글 **켜기**

> ✅ 켠 뒤에는 **브라우저를 완전히 종료했다가 다시 켜 주세요.**

### 3단계 — PIP 스크립트 설치
👉 **[PIP 설치하기](https://raw.githubusercontent.com/goguma613/video-pip/main/video-pip.user.js)** — "설치" 버튼만 누르면 끝!

> v1(1.x)을 쓰고 있었다면 자동으로 2.0으로 업데이트되고, 창 크기와 자동 PIP 설정은 그대로 옮겨집니다.

## 🎮 사용법

1. 영상에 마우스를 올리면 오른쪽 위에 **⧉** 버튼이 나타납니다. 누르면 작은 창으로 빠져나옵니다. (`Alt+P`도 같음)
2. 작은 창에 마우스를 올리면 컨트롤이 나타납니다. **휠 = 볼륨**, **`Shift`+휠 = 배속**.
3. 하단의 화질 표시(예: `1080p`)는 지금 실제로 재생 중인 해상도입니다. 유튜브에선 누르면 화질 목록이 바로 뜹니다.
   - **최고 화질 · 항상**: 영상이 바뀌어도 늘 그 영상의 최고 화질로
   - 특정 화질(예: 720p): 지금 보는 영상에만
   - **자동**: 유튜브에 맡김(기본값)
   > PiP 자체는 화질을 깎지 않습니다(재생 중인 영상을 그대로 옮김). 다만 유튜브가 "자동"일 때는 페이지 안 플레이어 크기·네트워크에 맞춰 화질을 낮출 수 있어서, 확실히 최고 화질로 보고 싶다면 **최고 화질 · 항상**을 고르세요.
4. 창 오른쪽 위 **⚙**에서 설정을 바꿀 수 있습니다.
   - 탭 전환 시 자동 PIP
   - 영상 위 ⧉ 버튼 표시
   - 이 사이트에서는 버튼·자동 PIP 끄기 (꺼도 `Alt+P`는 동작)
5. **✕**, `Esc`, 또는 브라우저의 "탭으로 돌아가기"로 닫으면 영상이 제자리로 돌아갑니다.

### ⌨️ 단축키

| 키 | 동작 | 키 | 동작 |
|---|---|---|---|
| `Alt+P` | PIP 켜기/끄기 (어디서나) | `↑` / `↓` | 볼륨 ±5% |
| `Space` / `K` | 재생·일시정지 | `M` | 음소거 |
| `←` / `→` | 5초 이동 | `[` / `]` | 배속 −/+0.25 |
| `J` / `L` | 10초 이동 | `=` | 배속 1배 |
| `Esc` | 설정 닫기 → PIP 닫기 | | |

- `Alt+P` 말고는 **PIP 창 안에서만** 동작합니다. 원래 페이지에서는 사이트 단축키가 그대로 살아 있어요.
- 한/영 상태와 상관없이 동작합니다. (macOS는 `Option+P`)

## 🐞 문제 신고

어떤 사이트에서 무엇을 했을 때 어떻게 됐는지 알려 주세요. 페이지를 이동할 때 PiP 영상이 멈추거나 검게 되는 문제라면 진단 기록이 큰 도움이 됩니다.

1. 그 사이트에서 개발자 도구(`F12`) → Console 탭에 `localStorage.setItem('vpip:debug', '1')` 입력 → 새로고침
2. 문제를 다시 재현한 뒤, 콘솔의 `[video-pip][진단]` 줄들을 복사해서 보내 주세요
3. 끄기: `localStorage.removeItem('vpip:debug')`

## 🛠 만든 사람을 위한 메모

설계는 [docs/DESIGN.md](docs/DESIGN.md), 출시 전 확인 목록은 [docs/QA.md](docs/QA.md)에 있습니다.

```bash
npm install
npm run dev           # 감시 빌드 + http://localhost:8787/video-pip.user.js 에서 설치/업데이트
npm run build         # video-pip.user.js 생성 (이 파일을 커밋)
npm run typecheck
npm test              # 단위 테스트
npm run test:browser  # 실제 Chromium에서 PIP 동작 확인 (처음 한 번: npx playwright install chromium)
```

- 소스는 `src/`의 TypeScript 모듈이고, 빌드하면 저장소 루트의 `video-pip.user.js` 한 파일이 됩니다. 압축하지 않으므로 설치하는 사람이 그대로 읽을 수 있습니다.
- 배포: `package.json`의 `version`을 올림 → `npm run build` → 커밋 → `main`에 머지하면 설치한 사람들에게 자동 업데이트됩니다.
- `@name` · `@namespace`(scripts/meta.mjs)를 바꾸면 기존 설치와 다른 스크립트로 인식되니 바꾸지 마세요.
