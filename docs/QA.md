# 출시 전 확인 목록

`npm run test:browser`가 실제 Chromium(headless)에서 자동으로 확인하는 항목은 ✅로 표시했다.
나머지는 실제 브라우저 + 유저스크립트 매니저 + 실제 사이트에서 손으로 확인한다.

## 자동 확인 (`npm run test:browser`)

| 항목 | 상태 |
|---|---|
| 영상 hover → ⧉ 버튼, 클릭 → PiP 창으로 이동, 계속 재생 | ✅ |
| 흐름 영상 자리 보존(아래 문단 위치 그대로), absolute 영상은 빈 상자 없음 | ✅ |
| 요청 창 크기 = 영상 비율(가로 480×270, 세로 270×480) | ✅ |
| 단축키(한글 key 값이어도 `e.code`로 동작), 휠/Shift+휠, 배속 칩, 시크바 | ✅ |
| ⚙ 팝오버 토글, Esc는 팝오버만 닫음 | ✅ |
| ✕ → DOM이 처음과 완전히 같음, 재생 상태 유지 | ✅ |
| `Alt+P` 열기/닫기, 3연타 시 상태 일관 | ✅ |
| 유튜브형 페이지: 제목 정리·갱신, 사이트 단일키 보존, 입력창 무시, 전체화면 인계, style 보존 | ✅ |
| SPA 영상 교체 → 새 영상으로 갈아 끼움 | ✅ |
| iframe 안 영상 → 기본 PiP | ✅ |
| `controls` 속성 영상: 기본 컨트롤 숨김, 속성 보존 | ✅ |
| 영상 없는 페이지에서 오류 없음 | ✅ |
| 유튜브 라이브(길이가 유한) → `LIVE` 표시, 클릭 시 유튜브 방식으로 실시간 이동 | ✅ |
| 유튜브 일반 ↔ 쇼츠 이동 → PiP가 새 영상으로, 이전 영상은 제자리로, 제목 갱신 | ✅ |
| PiP 영상 재생 중에는 페이지의 다른 영상이 재생돼도 바꾸지 않음 | ✅ |
| 유튜브: PiP로 보다가 홈으로 이동 → 계속 재생(늦게 멈추는 경우 포함), 사용자가 멈춘 영상은 그대로 | ✅ |
| 유튜브: 홈 이동 때 영상이 비워지면(src 제거 + load) 같은 영상을 보던 위치부터 다시 불러와 재생, 이동할 곳 정보가 없어도 동작, 사용자가 멈춘 영상·다른 영상으로 갈 때는 하지 않음 | ✅ |
| 진단 모드(`vpip:debug`)에서 사이트가 보낸 명령이 콘솔에 기록됨 | ✅ |
